LankaNow — Minimal Glass UI Redesign
====================================

Design direction
- Original interface inspired by the provided editorial dashboard reference, without copying it.
- Monochrome black / white / graphite palette.
- Subtle frosted-glass surfaces and soft grain texture.
- Desktop editorial side rail + compact sticky top bar.
- Large cinematic lead story, separate live-signal / trending column.
- Clean story cards, section discovery, and quieter typography.
- Responsive mobile drawer navigation.

- templates/news/card.html

Backend / admin
